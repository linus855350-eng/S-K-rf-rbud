# 🚔 S Körförbud

Ett gratis FiveM-script för polis-RP där poliser kan placera körförbud på fordon med fri Gizmo-placering.

Alla körförbud sparas i databasen, synkas mellan spelare och finns kvar efter server- och resursrestart.

## 🎥 Showcase

▶️ [Se videon på YouTube](DIN_YOUTUBE_LÄNK)

## ✨ Funktioner

- Fri Gizmo-placering
- Endast tillgängligt för polis
- Databaslagring
- Sparas efter serverrestart
- Synkroniserat mellan spelare
- Server-side validering
- Enkel installation

## 📦 Installation

1. Lägg resursen i din `resources`-mapp.
2. Lägg till följande i `server.cfg`:

```cfg
